# Deploying Markdown on Github Pages

## What is Markdown?

Markdown is a language designed to have _minimal_ structure to help our web browser show a **specifically** designed experience. Through this lesson, you will see some of the attributes you can add to decorate your files so that they show up a certain way in the browser.

> Markdown is a simple way to format text that looks great on any device. It doesn’t do anything fancy like change the font size, color, or type — just the essentials, using keyboard symbols you already know.
